# ページ指定の書式

ページ番号は 1 から数える。テストは `app/src/lib/pageRangeParser.test.ts` にある。

| ID | 要求 |
| :--- | :--- |
| SPEC-1 | カンマで区切った単一ページと範囲を受け付ける（`1, 3, 5-12`）。全角の数字、ハイフン、カンマも同じに扱う |
| SPEC-2 | 片側の範囲（`10-`、`-5`）と `end` を受け付ける |
| SPEC-3 | キーワード `all`、`odd`、`even` を受け付ける |
| SPEC-4 | `!` または `^` で除外する。除外だけの指定は全ページから除く |
| SPEC-5 | `pages` は昇順で重複なし。`orderedPages` は記述の順で、逆順の範囲（`5-3`）と重複を保つ |
| SPEC-6 | 範囲外のページ（`0` を含む）と解釈できない入力はエラーとし、エラーの文にそのページや入力を含める |
| SPEC-7 | 空の入力はエラーにせず、何も選ばない |
| SPEC-8 | 分割は、範囲のリスト（`;` 区切り）、区切りのページ番号、N ページごとの 3 通り |

書式を変えるときは、[ユーザーマニュアル §3](../user_manual.md#3-ページ指定の書式) とヘルプの画面（`ShortcutHelpModal.svelte`）も直す。
