# 保存の動作

| ID | 要求 | 確かめるテスト |
| :--- | :--- | :--- |
| SAVE-1 | 全ページの保存は元の文書を直接編集し、しおり、フォーム、文書情報を保持する。回転、並べ替え、注釈の追加があっても保持する | `pdfEngine.save.test.ts`、E2E「saving keeps…」 |
| SAVE-2 | 抽出、分割の出力は文書情報だけを引き継ぐ。結合の出力は引き継がない | `pdfEngine.save.test.ts` |
| SAVE-3 | 暗号化された PDF は閲覧のみとする。出力のすべての経路で拒否する。pdf-lib は復号できず、そのまま書き出すと白紙になるため | `pdfEngine.save.test.ts`、E2E「an encrypted PDF…」 |
| SAVE-4 | 削除したページは出力ファイルに残さない。そのページへの参照、しおり、入力欄、構造情報も取り除く | `pdfEngine.save.test.ts` |
| SAVE-5 | 注釈は PDF.js の表示領域（CropBox と MediaBox の共通部分）を基準に配置する | `pdfEngine.save.test.ts` |
| SAVE-6 | 注釈の座標は表示座標で持ち、ページを回転するときに一緒に変換する | `annotationRotation.test.ts` |
| SAVE-7 | 書き込みは一時ファイルを経由する。失敗しても既存のファイルは変わらず、一時ファイルも残らない | `lib.rs` のテスト、E2E「overwrite asks…」 |
| SAVE-8 | 複数の出力は、全件の検査と一時ファイルの書き込みが済んでから置き換える | `lib.rs` のテスト |
| SAVE-9 | 出力先の拡張子は `.pdf` に限る | `lib.rs` のテスト、E2E「the backend refuses…」 |
| SAVE-10 | 未保存の編集があるとき、閉じる前と別の PDF を開く前に確認する。再読み込みのキーは無効にする | E2E「unsaved edits…」「keys…」 |

## 判断の記録

- **新しい文書へコピーしない理由（SAVE-1）**: pdf-lib の `copyPages` はページだけを複製するので、カタログにあるしおりやフォームが失われる。
- **直接編集で削除を掃除する理由（SAVE-4）**: pdf-lib はコンテキストにある間接オブジェクトをすべて書き出すので、ページツリーから外しただけではページの内容がファイルに残る。
- **構造情報を消す理由（SAVE-4）**: 構造ツリーは削除したページの代替テキストを持ちうる。アクセシビリティ情報よりも、削除した内容を残さないことを優先する。ページを削除しない保存では消さない。
- **注釈を焼き込む理由**: 実装を単純に保ち、日本語の表示を環境によらず同じにするため。PDF 標準の注釈への移行は将来の課題とする。
