# `guif-pdf` ユーザーマニュアル

`guif-pdf` は、OSS 技術（Tauri 2 + Rust + Svelte 5 + PDF.js + pdf-lib）のみで構築された、`guif` 連携対応の PDF 閲覧・注釈・ページ編集ツールです。

---

## 1. 画面構成とツールバーの折りたたみ

PDF 閲覧時の視認性を最大化するため、上部には **1行のメニューバー** のみを常時表示し、詳細な操作バーは標準で折りたたんでいます。

| バー / パネル | 既定の状態 | 展開 / 折りたたみ方法 | 主な用途 |
| :--- | :--- | :--- | :--- |
| **メニューバー** | 常時表示 | `Alt+F`, `Alt+E`, `Alt+V`, `Alt+P`, `Alt+A`, `Alt+H` またはクリック | 全機能の呼び出し、ページ移動・ズーム、各バーの展開切替 |
| **左サイドパネル** | 表示 | `Ctrl+B` または メニュー「表示」→「左サイドパネルを表示」 | ページサムネイル一覧、注釈一覧、目次（しおり）、フォルダー内 PDF ブラウズ |
| **ページ操作・番号指定バー** | **折りたたみ** | `F2` または メニューバー右側の **`[📄 ページ操作 ▾]`** | ページ番号・範囲指定（`1-5, 8, !2` 等）による一括選択、回転・抽出・分割・結合・削除 |
| **注釈ツールバー** | **折りたたみ** | `F3` または メニューバー右側の **`[✎ 注釈ツール ▾]`** | ハイライト・文字記入・付箋・図形ツールの切替、色・文字サイズ・線幅の変更 |
| **テキスト検索バー** | **折りたたみ** | `Ctrl+F` または メニュー「編集」→「PDF内テキスト検索」 | PDF 内のテキスト検索と該当ページへのジャンプ |

## 2. メニューバー構成

すべての機能は上部のメニューバーから直接呼び出すことができます。

- **ファイル(`F`)**
  - フォルダーパネルからPDFを開く (`Ctrl+B`)
  - 別名で保存 (`Ctrl+S`)
  - 元ファイルに上書き保存 (`Ctrl+Shift+S`)
  - 指定ページを抽出して保存...
  - PDFを複数ファイルに分割...
  - 複数のPDFファイルを結合...
- **編集(`E`)**
  - 元に戻す (`Ctrl+Z`) / やり直す (`Ctrl+Y`)
  - PDF内テキスト検索 (`Ctrl+F`)
  - 現在ページを選択/解除 (`Space`)、全ページ選択 (`all`)、選択解除、選択反転、奇数ページ選択 (`odd`)、偶数ページ選択 (`even`)、現在ページ〜末尾を選択
- **表示(`V`)**
  - 左サイドパネル (`Ctrl+B`) / ページ操作バー (`F2`) / 注釈ツールバー (`F3`) の表示切替
  - レイアウト切替：連続スクロール表示 / 単一ページ表示 / 一覧グリッド表示
  - ズーム：拡大 (`Ctrl++`) / 縮小 (`Ctrl+-`) / ウィンドウ幅に合わせる (`W`) / 1ページ全体に合わせる (`F`)
  - テーマ切替：`guif連携` / `Nord` / `Default` / `Catppuccin` / `Monokai` / `Solarized` / `Light`
- **ページ操作(`P`)**
  - ページ番号指定・操作バーを展開/折りたたみ (`F2`)
  - 右に90°回転 (`R`) / 左に90°回転 (`Shift+R`) / 180°回転
  - 選択（または現在）ページを削除
  - ページ抽出 / PDF分割 / PDF結合ダイアログを開く
- **注釈(`A`)**
  - 注釈ツールバーを展開/折りたたみ (`F3`)
  - ツール切替：選択 (`V`) / ハイライト (`H`) / 文字記入 (`T`) / 付箋メモ (`N`) / 四角枠 (`B`) / 矢印 (`A`) / 直線 (`L`) / 手書きペン (`P`)
  - 注釈カラーの切替（イエロー / グリーン / シアン / ピンク / レッド）
  - 全ページの注釈をすべて消去
- **ヘルプ(`H`)**
  - ショートカットキー＆ページ指定書式一覧 (`?`)

## 3. ページ番号指定の書式（大量ページの高速・確実な操作）

ページ操作バー（`F2`）、ページ抽出ダイアログ、PDF分割ダイアログ、PDF結合ダイアログでは、GUI でのチェックボックス選択に加えて、以下のページ指定構文を利用できます（全角の数字・ハイフン・カンマも自動で半角として解釈されます）。

| 入力例 | 意味 |
| :--- | :--- |
| `1, 3, 5-12` | 1ページ目、3ページ目、および 5〜12ページ目を指定 |
| `10-` または `10-end` | 10ページ目から最終ページまでを指定（`-5` は 1〜5ページ目） |
| `all` / `odd` / `even` | 全ページ / 奇数ページのみ / 偶数ページのみを指定 |
| `1-50, !12, !20-25` | 1〜50ページのうち、12ページ目と 20〜25ページ目を**除外** |
| `!1` | 先頭に `!` を記述した場合は「全ページから P.1（表紙）を除外」 |
| `10, 1-5` | ページ抽出時に「記述した順番どおりに並べる」を有効にすると、10ページ目を先頭にした順で抽出可能 |

## 4. キーボードショートカット一覧

| キー | 動作 |
| :--- | :--- |
| `J` / `↓` / `PageDown` | 次のページへ移動 |
| `K` / `↑` / `PageUp` | 前のページへ移動 |
| `Home` / `End` | 先頭ページ / 最終ページへ移動 |
| `Space` | 現在表示中のページの選択チェックを ON / OFF |
| `F2` | ページ操作・番号指定バーを展開 / 折りたたみ |
| `F3` | 注釈ツールバーを展開 / 折りたたみ |
| `Ctrl+B` | 左サイドパネルを表示 / 非表示 |
| `Ctrl+F` | PDF内テキスト検索バーを表示 / 非表示 |
| `R` / `Shift+R` | 選択ページ（未選択時は現在ページ）を右90°回転 / 左90°回転 |
| `W` / `F` | ウィンドウ幅に合わせる / 1ページ全体に合わせる |
| `V` / `H` / `T` / `N` | 選択モード / ハイライト / 文字記入 / 付箋メモ |
| `B` / `A` / `L` / `P` | 四角枠 / 矢印 / 直線 / 手書きペン |
| `Delete` / `Backspace` | 選択中の注釈を削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す (Undo) / やり直す (Redo) |
| `Ctrl+S` / `Ctrl+Shift+S` | 別名で保存 / 元ファイルに上書き保存 |
| `?` | ショートカットキー＆ページ指定ヘルプを表示 |
