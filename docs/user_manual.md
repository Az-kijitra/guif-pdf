# guif-pdf ユーザーマニュアル（0.1.0）

`guif-pdf` は、Windows 10 / 11 向けの PDF 閲覧・注釈・ページ編集ツールです。

---

## 1. インストールとアンインストール

### 1.1 インストール

1. [Releases](https://github.com/Az-kijitra/guif-pdf/releases) からインストーラー `guif-pdf_0.1.0_x64-setup.exe` をダウンロードして実行します。
2. インストールは現在のユーザーだけに行われ、管理者権限は求められません。既定のインストール先は `%LOCALAPPDATA%\guif-pdf` です。
3. WebView2 ランタイムが無い PC では、インストーラーが取得して導入します（インターネット接続が必要です）。

コード署名が無いため、SmartScreen の警告が出ることがあります。「詳細情報」を選び、「実行」を押すと進めます。

### 1.2 アンインストール

Windows の「設定」→「アプリ」から「guif-pdf」を選びます。「アプリのデータを削除する」にチェックを入れると、設定も削除します。チェックを外したままなら、設定は残ります。

### 1.3 起動のしかた

- スタートメニューの「guif-pdf」から起動すると、前回のフォルダーを表示します。
- `guif-pdf.exe <PDFファイル>` で起動すると、その PDF を開きます。
- `guif-pdf.exe <フォルダー>` で起動すると、そのフォルダーを左パネルに表示します。
- PDF 以外のファイルを渡すと、そのファイルのあるフォルダーを表示します。

### 1.4 `guif` から起動する

[README](../README.md#guif-から起動する) の設定例を `guif` の `config.toml` に書きます。`guif` は `[[external_apps]]` を 1 つでも書くと既定の 4 つを使わなくなるので、既定の 4 つも残したいときは一緒に書いてください。

### 1.5 設定ファイル

設定は `%APPDATA%\dev.guif.pdf\settings.json` に自動で保存します。編集する必要はありません。内容はテーマ、最後に開いたフォルダー、PDF ごとの最後のページとズーム率です。PDF のパスがそのまま記録されるので、パスを残したくないときはこのファイルを削除してください。

## 2. 画面構成

PDF を広く表示するため、上部には 1 行のメニューバーだけを常に表示し、操作バーは既定で折りたたんでいます。

| バー / パネル | 既定 | 開き方 | 主な用途 |
| :--- | :--- | :--- | :--- |
| メニューバー | 常に表示 | `Alt+F`, `Alt+E`, `Alt+V`, `Alt+P`, `Alt+A`, `Alt+H` またはクリック | すべての機能、ページ移動、ズーム |
| 左サイドパネル | 表示 | `Ctrl+B` | サムネイル、注釈一覧、目次、フォルダー |
| ページ操作バー | 折りたたみ | `F2` | ページ指定、回転、抽出、分割、結合、削除 |
| 注釈ツールバー | 折りたたみ | `F3` | ツール、色、文字サイズ、線の太さの変更 |
| テキスト検索バー | 折りたたみ | `Ctrl+F` | PDF 内のテキスト検索 |

ステータスバーには、処理の結果、選択しているページ数、現在のツール、ズーム率を表示します。暗号化された PDF を開いているときは「閲覧のみ」と表示します。

### メニューバー

- **ファイル(`F`)**: フォルダーパネルから PDF を開く / 別名で保存 / 元ファイルに上書き保存 / ページ抽出 / 分割 / 結合
- **編集(`E`)**: 元に戻す / やり直す / PDF 内テキスト検索 / ページの選択（現在ページ、全ページ、解除、反転、奇数、偶数、現在ページから末尾まで）
- **表示(`V`)**: 各バーの表示切替 / 連続スクロール・単一ページ・一覧グリッド / ズーム / テーマ
- **ページ操作(`P`)**: 回転 / 削除 / 抽出・分割・結合のダイアログ
- **注釈(`A`)**: ツールの切替 / 色の切替 / すべての注釈の消去
- **ヘルプ(`H`)**: ショートカットキーとページ指定の一覧

テーマは `guif連携` / `Nord` / `Default` / `Catppuccin` / `Monokai` / `Solarized` / `Light` から選びます。`guif連携` は `guif` の `[theme]` の `preset` に合わせます。`guif` の `[colors]` と `[font]` は反映されません。

## 3. ページ指定の書式

ページ操作バーと、抽出・分割・結合のダイアログで使えます。全角の数字・ハイフン・カンマも使えます。

| 入力例 | 意味 |
| :--- | :--- |
| `1, 3, 5-12` | 1、3、5〜12 ページ |
| `10-` または `10-end` | 10 ページから最後まで |
| `-5` | 1〜5 ページ |
| `end` | 最後のページ |
| `all` / `odd` / `even` | 全ページ / 奇数ページ / 偶数ページ |
| `1-50, !12, !20-25` | 1〜50 ページから 12 と 20〜25 を除く（`!` の代わりに `^` も使えます） |
| `!1` | 全ページから 1 ページを除く（先頭が除外のときは全ページが対象です） |
| `10, 1-5` | 抽出で「記述した順に並べる」を有効にすると、10 ページ目を先頭にします |
| `5-3` | 抽出で順序を指定するときは、5、4、3 の順にします |

分割では、次の書き方も使えます。

- ページ範囲のリスト: `1-10; 11-25; 26-end`
- 区切りのページ番号（その直後で分割）: `5, 15, 30`
- N ページごと: `10`

## 4. キーボードショートカット

メニューの `Alt+` のキーと `Ctrl+` のキー以外は、Ctrl や Alt を押していないときだけ働きます。文字を入力している間とダイアログを開いている間も働きません。

| キー | 動作 |
| :--- | :--- |
| `J` / `PageDown` | 次のページへ移動 |
| `K` / `PageUp` | 前のページへ移動 |
| `Home` / `End` | 先頭ページ / 最終ページへ移動 |
| `Space` | 現在のページの選択を ON / OFF |
| `F2` | ページ操作バーを開閉 |
| `F3` | 注釈ツールバーを開閉 |
| `Ctrl+B` | 左サイドパネルを開閉 |
| `Ctrl+F` | テキスト検索バーを開閉 |
| `R` / `Shift+R` | 選択ページ（無ければ現在のページ）を右に 90° / 左に 90° 回転 |
| `W` / `F` | 幅に合わせる / ページ全体に合わせる |
| `V` / `H` / `T` / `N` | 選択 / ハイライト / 文字記入 / 付箋 |
| `B` / `A` / `L` / `P` | 四角枠 / 矢印 / 直線 / 手書きペン |
| `Delete` / `Backspace` | 選択中の注釈を削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す（`Ctrl+Shift+Z` でもやり直せます） |
| `Ctrl+S` / `Ctrl+Shift+S` | 別名で保存 / 元ファイルに上書き保存 |
| `?` | ヘルプを開く |
| `Esc` | ダイアログを閉じる。ダイアログが無ければ選択ツールに戻る |

`↑` / `↓` は表示をスクロールします。`F5` と `Ctrl+R` の再読み込みは無効にしています（未保存の編集が消えるのを防ぐためです）。

## 5. 注釈

| ツール | 使い方 |
| :--- | :--- |
| ハイライト | 文字をドラッグして選ぶか、図表やスキャンした PDF では範囲をドラッグします |
| 文字記入 | クリックした位置に入力します。白い背景の有無と文字サイズを変えられます |
| 付箋 | クリックした位置にメモカードを置きます |
| 四角枠 / 矢印 / 直線 | ドラッグして描きます |
| 手書きペン | ドラッグした軌跡を描きます |

選択ツールでは、注釈をドラッグして移動できます。文字記入と付箋はダブルクリックで編集できます。移動と文字の編集も `Ctrl+Z` で元に戻せます。

ページを回転すると、注釈もページの内容と一緒に移動します。文字記入と付箋は、画面の上で正立したまま位置だけが変わります。

## 6. 保存の仕組みと制限事項

### 6.1 保存の方法

| 操作 | 動作 |
| :--- | :--- |
| 別名で保存（`Ctrl+S`） | `_edited.pdf` などの重複しない名前を提案します。保存するまで元のファイルは変わりません |
| 上書き保存（`Ctrl+Shift+S`） | 確認の後に、元のファイルを置き換えます |

保存はいったん一時ファイルに書き出してから置き換えます。書き込みに失敗しても、元のファイルはそのまま残ります。複数のファイルを出力するときも、すべての一時ファイルを書き終えてから置き換えます。

### 6.2 保存で引き継ぐもの

| 情報 | 全ページの保存 | 抽出・分割 | 結合 |
| :--- | :--- | :--- | :--- |
| ページの内容と既存の注釈 | ○ | ○ | ○ |
| 回転 | ○ | ○ | ○（ファイルごとに指定） |
| 本アプリの注釈 | ○（焼き込み） | ○（焼き込み） | 編集中の PDF だけ○（焼き込み） |
| タイトル・作成者などの文書情報 | ○ | ○ | × |
| しおり（目次） | ○ | × | × |
| フォーム（入力欄の定義） | ○ | × | × |



### 6.3 ページを削除して保存するとき

削除したページのデータは、出力ファイルから取り除きます。次の点に注意してください。

- 削除したページを指すしおりは消えます。子のしおりが残っているものは、見出しとして残ります。名前付きの移動先を使うしおりは残りますが、選んでも移動しません。
- 削除したページだけにある入力欄は消えます。
- PDF のアクセシビリティ用の構造情報（タグ）は削除します。削除したページの本文を含むことがあるためです。

### 6.4 制限事項

- **注釈は焼き込みです。** 保存すると、ページの内容の一部になります。保存後は注釈として移動や削除ができません。また、PDF の標準の注釈ではないので、他の PDF ビューアの注釈一覧には出ません。
- **文字記入と付箋は画像です。** 検索とコピーの対象になりません。フォントは Windows の BIZ UDGothic / Yu Gothic UI / Meiryo を使います。
- **暗号化された PDF は閲覧のみです。** 回転、削除、注釈、保存、抽出、分割はできません。結合のリストにも追加できません。
- **パスワードが必要な PDF は開けません。**
- **電子署名は無効になります。** 署名付きの PDF を保存すると、署名は有効でなくなります。
- **ファイル全体をメモリーに読み込みます。** 非常に大きな PDF では、メモリーを多く使います。開発環境の計測では、500 ページ・50 MB の PDF は起動を含めて約 4 秒で開き、約 3 秒で保存できました。

## 7. トラブルシューティング

| 症状 | 原因と対処 |
| :--- | :--- |
| 「閲覧のみ」と表示され、編集できない | 暗号化された PDF です。編集できません（§6.4） |
| 「パスワードが必要な PDF は開けません」と表示される | 開くときにパスワードが必要な PDF です。対応していません |
| 「同名のファイルが既に存在します」と表示される | 保存ダイアログで別の名前を指定するか、上書きを許可してください |
| 「保存先のファイル名は .pdf で終わる必要があります」と表示される | ファイル名の末尾に `.pdf` を付けてください |
| 保存すると署名が無効になる | 仕様です（§6.4）。署名を残したいときは保存しないでください |
| 保存した文字記入を検索できない | 画像として書き込むためです（§6.4） |
| `guif` で既定の外部アプリが消えた | `[[external_apps]]` を書くと既定の 4 つは使われません。[README の例](../README.md#guif-から起動する)のように一緒に書いてください |
| `guif` の配色の一部が反映されない | `preset` だけを読みます。`[colors]` と `[font]` は反映されません |
| SmartScreen の警告が出る | コード署名が無いためです。「詳細情報」→「実行」で進めます |
| 起動しない | WebView2 ランタイムが入っているか確認してください |

不具合の報告は [Issues](https://github.com/Az-kijitra/guif-pdf/issues) へお願いします。
